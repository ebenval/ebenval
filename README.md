## 🚀 Proyecto Destacado

### 🧳 AgenciaViajes
> Un proyecto en **Python**, usando **SQLAlchemy** y **SQLite**, que simula una agencia de viajes.  
> Permite gestionar destinos, clientes y reservas con una base de datos estructurada en tres archivos principales.

- `main.py` → Control de la aplicación  
- `models.py` → Clases y relaciones ORM  
- `db.py` → Conexión y creación de la base de datos
